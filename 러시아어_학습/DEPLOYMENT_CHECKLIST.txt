================================================================================
배포 진행 - GitHub 저장소 생성 단계
================================================================================

[ ] Step 1: GitHub.com에 로그인했음
[ ] Step 2: https://github.com/new 에서 새 저장소 생성

    [ ] Description: (선택사항)
    [ ] Public 선택 (중요!!)

[ ] Step 3: "Create repository" 클릭
[ ] Step 4: 저장소 생성됨 (URL 형식: https://github.com/[USERNAME]/russian-learning)

================================================================================
배포 진행 - Git 푸시 단계
================================================================================

[ ] Step 1: 이 폴더에서 터미널 열기
[ ] Step 2: 다음 명령어 실행:
    [ ] git init (완료, 메시지: Initialized empty Git repository)
    [ ] git remote add origin https://github.com/YOUR_USERNAME/russian-learning.git
        (YOUR_USERNAME을 자신의 GitHub 이름으로 변경)
    [ ] git add . (완료, 메시지 없음)
    [ ] git commit -m "Initial commit" (완료, 파일 목록 표시)
    [ ] git branch -M main (완료, 메시지 없음)
    [ ] git push -u origin main (GitHub 로그인 후 완료)
        - Windows에서 브라우저 창이 열릴 수 있음
        - GitHub 계정으로 로그인
        - 성공 메시지: "branch 'main' set up to track 'origin/main'"

터미널 확인:
[ ] 모든 명령어가 오류 없이 완료됨
[ ] 마지막 메시지가 성공적 푸시 표시

문제 해결 - 체크사항
================================================================================

문제 발생 시 다음을 확인하세요:

Git 오류:
[ ] "git: command not found"
    → Git 설치 (https://git-scm.com)
    → 터미널 재시작

[ ] "fatal: not a git repository"
    → git init 실행하지 않음
    → git init 실행

[ ] "fatal: 'origin' does not appear to be a 'git' repository"
    → git remote add 명령어가 잘못되었거나 실행되지 않음
    → 저장소 URL 확인 (YOUR_USERNAME을 실제 이름으로 변경)

[ ] "403 Forbidden" (푸시 오류)
    → GitHub 로그인 필요
    → 로그인 창에서 GitHub 계정으로 로그인
    → 저장소 접근 권한 확인

GitHub Pages 오류:
[ ] "Your site is not published" (배포 안 됨)
    → Settings > Pages 확인
    → Source: "Deploy from a branch" 선택
    → Branch: "main", Folder: "/" 선택
    → Save 클릭
    → 1-2분 대기 후 새로고침

[ ] "404 Not Found" (사이트 없음)
    → URL이 정확한지 확인
    → https://YOUR_USERNAME.github.io/russian-learning/ (정확한 형식)
    → GitHub Pages 배포 완료 대기 (1-2분)
    → 브라우저 캐시 지우고 새로고침 (Ctrl+Shift+R)

웹사이트 로드 오류:
[ ] 스타일이 깨짐 (색상/레이아웃 안 보임)
    → 브라우저 강제 새로고침 (Ctrl+Shift+R)
    → 다른 브라우저에서 시도

[ ] 리소스 로드 실패 (404 오류)
    → index.html이 root에 있는지 확인
    → GitHub에 모든 파일이 푸시되었는지 확인
