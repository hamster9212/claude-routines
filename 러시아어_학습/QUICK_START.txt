================================================================================
러시아어 학습 웹사이트 - 퀵 스타트 (5분)
================================================================================

전체 단계를 이미지로 보여줍니다. 아래 명령어를 그대로 복사-붙여넣기하세요.

================================================================================
STEP 1: GitHub 저장소 생성 (브라우저에서)
================================================================================

1. https://github.com/new 방문 (또는 GitHub > New)

2. 입력 항목:
   Repository name: russian-learning
   Description: (비워둬도 됨)
   Public 선택 (중요!)
   ☐ Add a README file (체크 해제)

3. Create repository 클릭

4. 생성된 저장소 URL 복사:
   https://github.com/[YOUR_USERNAME]/russian-learning

================================================================================
STEP 2: 로컬에서 배포 (터미널)
================================================================================

다음 명령어를 복사-붙여넣기하세요:
(YOUR_USERNAME을 자신의 GitHub 이름으로 바꾸세요)

┌──────────────────────────────────────────────────────────────────────────┐
│ git init                                                                  │
│ git remote add origin https://github.com/YOUR_USERNAME/russian-learning  │
│ git add .                                                                 │
│ git commit -m "Initial commit"                                            │
│ git branch -M main                                                        │
│ git push -u origin main                                                   │
└──────────────────────────────────────────────────────────────────────────┘

※ 로그인 창 나오면 GitHub 계정으로 로그인

================================================================================
STEP 3: GitHub Pages 활성화 (브라우저에서)
================================================================================

1. GitHub 저장소 페이지로 이동

2. Settings 탭 클릭

3. 왼쪽 메뉴에서 "Pages" 클릭

4. 설정:
   Source: "Deploy from a branch"
   Branch: "main" + "/" 폴더

5. Save 클릭

6. 파란 배너에서 "Your site is live at..." 확인
   예: https://YOUR_USERNAME.github.io/russian-learning/

================================================================================
STEP 4: 확인
================================================================================

브라우저에서 다음 URL 방문:
https://YOUR_USERNAME.github.io/russian-learning/

완료! 축하합니다!

================================================================================
파일 설명
================================================================================

이 폴더의 파일들:

- index.html
  → 메인 학습 웹페이지 (완전한 러시아어 학습 앱)
  → GitHub에 푸시되면 위 URL에서 공개됨

- README.md
  → 이 프로젝트 설명 및 배포 방법
  → GitHub 저장소 메인 페이지에 자동 표시

- deploy.sh
  → 배포 자동화 스크립트 (선택사항)
  → bash deploy.sh 실행하면 안내 표시

- deployment_guide.txt
  → 상세 단계별 가이드 (이 파일보다 더 자세함)

- .gitignore
  → Git이 무시할 파일 목록
  → 자동 생성 파일들이 푸시되지 않도록 함

- QUICK_START.txt (이 파일)
  → 빠른 참조용 요약

================================================================================
도움말
================================================================================

Git 명령어 오류?
→ Git이 설치되지 않았을 수 있음
→ https://git-scm.com 에서 다운로드 후 설치
→ 터미널 재시작

푸시 오류 (403 Forbidden)?
→ GitHub 계정으로 로그인하지 않음
→ 로그인 창에서 GitHub 계정 입력

GitHub Pages가 활성화 안 됨?
→ Settings > Pages에서 확인
→ Branch: main, Folder: / (root) 선택 후 Save

URL에 접속 불가?
→ 배포 대기 (1-2분)
→ 페이지 새로고침
→ YOUR_USERNAME을 정확히 입력

더 자세한 도움:
→ deployment_guide.txt 참고
→ 문제 해결 섹션 참고
