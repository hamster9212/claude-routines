================================================================================
GitHub Pages 배포 플로우차트 (시각적 가이드)
================================================================================

START
  │
  ├─ 시작
  │  ├─ [ ] GitHub 계정 생성/확인 → https://github.com/signup
  │  ├─ [ ] Git 설치 확인 → https://git-scm.com
  │  └─ [ ] 이 폴더의 파일들 준비 완료
  │
  ├─ STEP 1: GitHub 저장소 생성 (3분)
  │  │
  │  ├─ [ ] GitHub.com에 로그인
  │  ├─ [ ] https://github.com/new 방문
  │  │
  │  └─ [저장소 생성 폼 작성]
  │     ├─ Repository name: russian-learning ✓ (필수)
  │     ├─ Description: (선택사항)
  │     ├─ Public 선택 ✓ (필수)
  │     └─ Add a README file: 체크 해제 ✓
  │
  │        [Create repository] 클릭
  │
  │        ↓
  │        저장소 생성됨!
  │        URL: https://github.com/YOUR_USERNAME/russian-learning
  │
  ├─ STEP 2: 로컬 배포 (2분)
  │  │
  │  ├─ [ ] 이 폴더에서 터미널 열기
  │  │   Windows: 오른쪽 클릭 > "터미널 열기" 또는 "PowerShell 여기서 열기"
  │  │   Mac: 터미널.app 열고 폴더로 cd
  │  │   Linux: 터미널 열고 폴더로 cd
  │  │
  │  └─ [다음 명령어 순서대로 실행]
  │     │
  │     ├─ git init
  │     │  └─ 출력: "Initialized empty Git repository"
  │     │
  │     ├─ git remote add origin https://github.com/YOUR_USERNAME/russian-learning.git
  │     │  └─ (YOUR_USERNAME을 자신의 이름으로 변경!)
  │     │
  │     ├─ git add .
  │     │  └─ (메시지 없음)
  │     │
  │     ├─ git commit -m "Initial commit"
  │     │  └─ 출력: 파일 목록과 통계
  │     │
  │     ├─ git branch -M main
  │     │  └─ (메시지 없음)
  │     │
  │     └─ git push -u origin main
  │        │
  │        ├─ 만약 로그인 창 나타남:
  │        │  └─ GitHub 계정으로 로그인
  │        │
  │        └─ 성공 메시지:
  │           "branch 'main' set up to track 'origin/main'"
  │
  ├─ STEP 3: GitHub Pages 활성화 (2분)
  │  │
  │  ├─ [ ] GitHub 저장소 페이지 방문
  │  │       https://github.com/YOUR_USERNAME/russian-learning
  │  │
  │  ├─ [ ] [Settings] 탭 클릭
  │  │   위치: Code | Issues | Pull requests | ... | Settings
  │  │
  │  ├─ [ ] 왼쪽 메뉴에서 [Pages] 클릭
  │  │   스크롤 필요할 수 있음
  │  │
  │  └─ [Pages 설정 구성]
  │     │
  │     ├─ Build and deployment 섹션:
  │     │  └─ Source: "Deploy from a branch" 선택
  │     │
  │     ├─ Branch 섹션:
  │     │  ├─ Branch: "main" 선택 ✓
  │     │  └─ Folder: "/" (root) 선택 ✓
  │     │
  │     └─ [Save] 버튼 클릭
  │        │
  │        ├─ 페이지 자동 새로고침
  │        │
  │        └─ 파란 배너 표시:
  │           "Your site is live at: https://YOUR_USERNAME.github.io/russian-learning/"
  │
  ├─ STEP 4: 배포 대기 (1-2분)
  │  │
  │  └─ [ ] 초록색 체크마크 표시 대기
  │        ├─ 처음에는 노란색 진행중 표시
  │        ├─ 1-2분 후 초록색 체크마크 ✓
  │        └─ 이 시간 동안 기다리거나 다른 일 하기
  │
  ├─ STEP 5: 확인 (1분)
  │  │
  │  ├─ [ ] 브라우저에서 다음 URL 방문:
  │  │       https://YOUR_USERNAME.github.io/russian-learning/
  │  │
  │  ├─ [ ] 페이지가 로드되는지 확인
  │  │   ├─ 로드됨 → Step 6으로 진행
  │  │   ├─ 로드 안 됨 → "배포 후 확인" 섹션 참고
  │  │   └─ 404 에러 → deployment_guide.txt의 Q4 참고
  │  │
  │  ├─ [ ] 웹사이트 기능 확인
  │  │   ├─ [ ] 색상 정상 (파란색 네비게이션 바 보임)
  │  │   ├─ [ ] 텍스트 정상
  │  │   ├─ [ ] 레이아웃 정상
  │  │   └─ [ ] 클릭 반응 있음
  │  │
  │  └─ 모든 확인 완료!
  │
  └─ END ✓ 축하합니다! 배포 성공!
     │
     └─ 이제 다음 할 일:
        ├─ 공개 URL을 친구들과 공유
        ├─ 소셜 미디어에 공개
        └─ 수정하려면 파일 수정 후 "git add . && git commit -m '...' && git push"


================================================================================
문제 발생 시 플로우
================================================================================

[문제 발생]
  │
  ├─ Git 오류?
  │  ├─ "git: command not found"
  │  │  └─ Git 설치 (https://git-scm.com)
  │  │     → 터미널 재시작
  │  │     → 다시 시도
  │  │
  │  └─ 다른 Git 오류
  │     └─ deployment_guide.txt의 "문제 해결" 섹션 참고
  │
  ├─ GitHub 오류?
  │  ├─ "403 Forbidden" (푸시 실패)
  │  │  ├─ 로그인 창 나타남 → GitHub 계정으로 로그인
  │  │  ├─ 다시 시도: git push
  │  │  └─ 여전히 실패하면 저장소 URL 확인
  │  │
  │  └─ 저장소 찾을 수 없음
  │     └─ https://github.com/new 에서 저장소 다시 생성
  │
  ├─ GitHub Pages 오류?
  │  ├─ "Your site is not published"
  │  │  ├─ Settings > Pages 확인
  │  │  ├─ Source: "Deploy from a branch"
  │  │  ├─ Branch: "main"
  │  │  ├─ Folder: "/"
  │  │  └─ Save 클릭
  │  │
  │  └─ 배포 대기 시간 초과
  │     └─ 1-2분 기다린 후 페이지 새로고침 (F5 또는 Ctrl+R)
  │
  └─ 웹사이트 로드 오류?
     ├─ "404 Not Found"
     │  ├─ URL이 정확한지 확인
     │  ├─ 브라우저 캐시 지우기 (Ctrl+Shift+R)
     │  └─ 1-2분 더 대기
     │
     └─ 스타일/색상 깨짐
        ├─ 강제 새로고침 (Ctrl+Shift+R)
        ├─ 다른 브라우저 시도
        └─ 배포 완료 대기 (1-2분)

================================================================================
시간 추정
================================================================================

총 소요 시간: 약 5-10분

구성:
  STEP 1 (GitHub 저장소 생성):  3분 ⏱
  STEP 2 (로컬 배포):            2분 ⏱
  STEP 3 (GitHub Pages 설정):    2분 ⏱
  STEP 4 (배포 대기):            1-2분 ⏱
  STEP 5 (확인):                 1분 ⏱
                     ─────────────────
                     총 9-11분 ⏱

만약 계정 생성이 필요하면:
  + 5분 (GitHub 계정 생성)
  = 14-16분 총 소요 시간


================================================================================
다음 단계
================================================================================

배포 완료 후:

1. URL을 친구들과 공유
   https://YOUR_USERNAME.github.io/russian-learning/

2. 웹사이트 수정하고 싶으면:
   ├─ 파일 수정 (index.html 등)
   ├─ 터미널에서 실행:
   │  git add .
   │  git commit -m "설명"
   │  git push
   └─ 1-2분 후 자동 반영

3. 자세한 정보:
   ├─ README.md
   ├─ deployment_guide.txt
   └─ GitHub Pages 공식: https://pages.github.com/
