================================================================================
기초러시아어 학습 웹사이트 - GitHub Pages 배포 완전 가이드
================================================================================

이 가이드는 처음부터 끝까지 웹사이트를 공개하는 모든 단계를 설명합니다.
총 소요 시간: 약 5-10분

================================================================================
사전 준비 (필수)
================================================================================

[ ] 1. GitHub 계정 확인/생성
   - 이미 있으면: GitHub.com에 로그인
   - 없으면: https://github.com/signup 에서 무료 가입

[ ] 2. Git 설치 확인
   Windows 사용자:
   - https://git-scm.com/download/win 에서 다운로드 및 설치
   - 설치 후 cmd 또는 PowerShell 재시작

   Mac 사용자:
   - 이미 설치되어 있을 가능성 높음
   - 터미널에서 "git --version" 실행하여 확인

   Linux 사용자:
   - 이미 설치되어 있을 가능성 높음
   - 없으면 "sudo apt-get install git" 실행

================================================================================
Step 1: GitHub 저장소 생성 (3분)
================================================================================

1.1) GitHub.com에 로그인
   - 오른쪽 상단 프로필 아이콘 클릭
   - "Your repositories" 클릭

1.2) 새 저장소 생성
   - 초록색 "New" 버튼 클릭
   - Repository name: "russian-learning" (정확히 입력)
   - Description: "기초러시아어 학습 웹사이트" (선택사항)
   - Public 선택 (필수! 공개 저장소여야 GitHub Pages 접근 가능)
   - "Add a README file" 체크 해제 (이미 README.md가 있음)
   - "Create repository" 클릭

1.3) 저장소 생성 완료 화면
   - 주소창에 이런 형태가 보임: https://github.com/YOUR_USERNAME/russian-learning
   - 이를 기록해두세요 (다음 단계에서 필요)

================================================================================
Step 2: 로컬 환경에서 파일 준비 및 푸시 (3분)
================================================================================

2.1) 터미널 열기
   Windows:
   - 파일 탐색기에서 russian-learning 폴더 오른쪽 클릭
   - "터미널 열기" 또는 "Windows PowerShell 여기서 열기" 클릭

   또는:
   - cmd 또는 PowerShell 열기
   - "cd" 명령으로 russian-learning 폴더로 이동

   Mac/Linux:
   - 터미널 애플리케이션 열기
   - "cd" 명령으로 russian-learning 폴더로 이동

2.2) 다음 명령어를 차례대로 실행
   (복사-붙여넣기 권장)

   명령어 1: Git 초기화
   ──────────────────────────────────────────────────────────────
   git init
   ──────────────────────────────────────────────────────────────

   명령어 2: 원격 저장소 설정
   (YOUR_USERNAME을 GitHub 사용자명으로 바꾸세요)
   ──────────────────────────────────────────────────────────────
   git remote add origin https://github.com/YOUR_USERNAME/russian-learning.git
   ──────────────────────────────────────────────────────────────

   명령어 3: 모든 파일 추가
   ──────────────────────────────────────────────────────────────
   git add .
   ──────────────────────────────────────────────────────────────

   명령어 4: 커밋 (변경사항 저장)
   ──────────────────────────────────────────────────────────────
   git commit -m "Initial commit: Russian language learning website"
   ──────────────────────────────────────────────────────────────

   명령어 5: 메인 브랜치 설정
   ──────────────────────────────────────────────────────────────
   git branch -M main
   ──────────────────────────────────────────────────────────────

   명령어 6: GitHub로 푸시 (업로드)
   ──────────────────────────────────────────────────────────────
   git push -u origin main
   ──────────────────────────────────────────────────────────────

   ※ 이 시점에서 GitHub 로그인 창이 나올 수 있습니다.
     GitHub 계정으로 로그인하세요.

2.3) 푸시 완료 확인
   - 터미널에 "branch 'main' set up to track 'origin/main'" 같은 메시지
   - 이 메시지가 나오면 성공!

================================================================================
Step 3: GitHub Pages 활성화 (2분)
================================================================================

3.1) GitHub 저장소 페이지로 이동
   - 브라우저에서 https://github.com/YOUR_USERNAME/russian-learning 방문
   - YOUR_USERNAME을 자신의 GitHub 사용자명으로 바꾸세요

3.2) Settings 탭 열기
   - 저장소 상단의 탭 중 "Settings" 클릭
   - (Code, Issues, Pull requests, ... Settings)

3.3) Pages 설정 찾기
   - 왼쪽 메뉴에서 "Pages" 클릭
   - (또는 왼쪽 메뉴 아래로 스크롤하면 "Pages" 보임)

3.4) GitHub Pages 설정
   - "Build and deployment" 섹션에서:
     Source: "Deploy from a branch" 선택
   - "Branch" 섹션에서:
     Branch: "main" 선택
     Folder: "/" (root) 선택
   - "Save" 버튼 클릭

3.5) 배포 대기
   - 페이지가 새로고침됨
   - 파란 배너가 보이면 "Your site is live at..." 확인
   - 보통 1-2분 소요 (기다린 후 새로고침)

================================================================================
Step 4: 공개 URL 확인 및 접속 (1분)
================================================================================

4.1) 공개 URL 확인
   Settings > Pages 페이지에서:
   "Your site is live at: https://YOUR_USERNAME.github.io/russian-learning/"

   이 주소를 기록합니다.

4.2) 브라우저에서 접속
   - 주소창에 위 URL 입력
   - Enter 누르기
   - 기초러시아어 학습 웹사이트가 보이면 성공!

================================================================================
문제 해결
================================================================================

Q1: "git: command not found" 또는 "git는 내부 또는 외부 명령이 아닙니다"
A: Git이 설치되지 않았습니다. https://git-scm.com 에서 다운로드하여 설치하세요.
   설치 후 터미널을 다시 시작하세요.

Q2: "git push" 중 "403 Forbidden" 에러
A: 다음 중 하나일 가능성:
   1. GitHub 계정으로 로그인하지 않았음 → 로그인 창에서 로그인
   2. 저장소 주소가 잘못됨 → YOUR_USERNAME을 정확히 입력했는지 확인
   3. 저장소가 Private → GitHub에서 Public으로 변경 (Settings > Danger Zone)

Q3: GitHub Pages가 활성화되지 않는 경우
A: Settings > Pages에서:
   - Source가 "Deploy from a branch"로 설정되어 있는지 확인
   - Branch가 "main"으로 설정되어 있는지 확인
   - Folder가 "/"(root)로 설정되어 있는지 확인

Q4: 공개 URL에 접속했지만 "404 Not Found" 에러
A: 다음 중 하나:
   1. 배포가 아직 진행 중 → 1-2분 대기 후 새로고침
   2. URL이 잘못됨 → YOUR_USERNAME을 정확히 입력
   3. index.html이 root에 없음 → 파일 위치 확인

Q5: 웹사이트는 보이지만 스타일(색상, 레이아웃)이 깨짐
A: 이 경우는 거의 없습니다. 브라우저 캐시 문제일 수 있습니다:
   - Ctrl+Shift+R (Windows) 또는 Cmd+Shift+R (Mac)로 강제 새로고침
