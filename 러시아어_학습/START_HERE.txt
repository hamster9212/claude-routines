배포 과정 요약 (정말 간단!)
================================================================================

[Step 1] GitHub에서 저장소 생성
├─ https://github.com/new 방문
├─ Repository name: russian-learning
├─ Public 선택
└─ Create

[Step 2] 터미널에서 명령어 실행
├─ git init
├─ git remote add origin https://github.com/YOUR_USERNAME/russian-learning.git
├─ git add .
├─ git commit -m "Initial commit"
├─ git branch -M main
└─ git push -u origin main

[Step 3] GitHub에서 Pages 활성화
├─ Settings > Pages 클릭
├─ Branch: main 선택
├─ Save 클릭
└─ 1-2분 대기

[Step 4] 완료!
└─ https://YOUR_USERNAME.github.io/russian-learning/ 방문

총 소요 시간: 약 5-10분
