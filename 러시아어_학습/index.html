🎵 КИНО — Группа крови (1988)

노래에 나온 단어

💡 연상기억법
3과 단어 43개를 재미있는 이야기로 외우기

📍 장소·시설

러시아어 뜻 연상기억법
рестора́н 레스토랑, 식당 레스토랑은 러시아어도 똑같이 '레스토란' — 그냥 외워!
компа́ния 회사 캠핑 가는 파니야(아줌마)들이 모인 곳 = 회사
о́фис 사무실 오피스는 사무실 — 영어랑 완전 동일
санато́рий 휴양소, 요양원 사나운 사람도 토리에서 쉬면 낫는다 = 요양원
парк 공원 파르크 — 파란 크레파스로 그린 곳 = 공원
больни́ца 병원 발이 니 아파서 짜증난다 = 병원
заво́д 공장 자봇 — 자동차 봇(로봇)이 만들어지는 곳 = 공장
стадио́н 경기장, 스타디움 스타디온 — 스타들이 디(뛰)는 온 세상 = 경기장
уро́к 수업, 과 우록 — 우리 록(rock) 수업 들어가자 = 수업
сад 정원 삿 — 삿갓 쓰고 정원 거닌다 = 정원
лес 숲 례스 — 레이스처럼 얽힌 나무들 = 숲
пол 바닥, 성별 뽈 — 뽈뽈 기어다니는 바닥 = 바닥
шкаф 옷장 쉬캬프 — 쉬면서 캬캬 웃으며 옷 꺼내는 장 = 옷장
аэропо́рт 공항 에어로(aero) 뽀르트 = 공항

러시아어 뜻 연상기억법
конце́рт 콘서트 깐쩨르트 — 발음이 'concert'랑 닮았다 = 콘서트
бале́т 발레 발렛 — 발레는 러시아어도 발렛 = 발레
о́пера 오페라 오페라 — 영어랑 똑같다 = 오페라
пе́нсия 연금 펜씨야 — 펜 씌워 야금야금 모은 돈 = 연금

🌍 나라

러시아어 뜻 연상기억법
Коре́я 한국 까례야 — 까리는 게 없는 예야(얘야)들의 나라 = 한국
Росси́я 러시아 라씨야 — 라씨(러시아식 음료) 마시는 나라 = 러시아
Кита́й 중국 끼따이 — 끼를 따이(따르는) 나라 = 중국
Япо́ния 일본 야포니야 — 야! 포니(조랑말)야! 하는 나라 = 일본
Аме́рика 미국 아메리카노 커피를 마시며 미국 드라마 본다
А́нглия 영국 앙! 글이야! 영국은 셰익스피어의 나라

👷 직업

러시아어 뜻 연상기억법
пенсионе́р 연금생활자 펜씨아녜르 — 펜 씩 아껴 쓰는 녀석, 연금으로 사는 할아버지
апте́карь 약사 압쩨까리 — 압박 체크 카리스마, 약사가 혈압 체크한다

бизнесме́н 사업가 비즈네스멘 — 비즈니스맨 = 사업가
инжене́р 엔지니어 인줴녜르 — 인줄 알았더니 줴대로 일하는 엔지니어
пова́р 요리사 뽀바르 — 뽀빠이 바로 요리사였어, 시금치 요리사
почтальо́н 우체부 뽀취딸욘 — 뽀취! 딸에게 욘(편지) 전하는 우체부
